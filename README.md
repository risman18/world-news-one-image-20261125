# The World Today — Wednesday, 25 November 2026

One image summing up the world's news of Wednesday 25 November 2026:
Ukraine confirms sea-drone strikes on the Russian cargo ship Sparta II in
the Gulf of Finland and the sinking of the corvette Merkury off Libya;

## The image

`entry.png` is a 1024×1024 broadsheet-style front page — masthead with
the date, lead story with a drawn sea-battle illustration, four more
stories with small drawn icons, and an "Also today" strip — rendered by
`render.py` with Pillow and the system DejaVu fonts.

## The program

`main.py` (Python 3, standard library only) copies the shipped
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
`/output/entry.png`). No network, no clock, no randomness: both runs
write identical bytes.
